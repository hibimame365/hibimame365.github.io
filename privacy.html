ひびまめ365 自動投稿

プライバシーポリシー

最終更新日：2026年10月20日

本ポリシーは、運営者が管理するYouTubeチャンネルの制作・予約投稿に使用する「ひびまめ365 自動投稿」（以下「本アプリ」）と、その案内サイトに適用します。

1. 取得する情報

  • GoogleのOAuth認証によるアクセストークン・更新トークンなどの認証情報。
  • 許可されたYouTubeチャンネルのID、名称、チャンネル情報。
  • 本アプリが投稿する動画、タイトル、説明、公開設定、公開予定日時。
  • 投稿した動画のID、アップロード・処理・公開状態、および投稿処理の結果。
  • お問い合わせの際に受け取るメールアドレスとお問い合わせ内容。

本アプリは、YouTubeへの動画アップロード権限と、YouTube情報の読み取り権限を要求します。認証時にはGoogleの同意画面に対象の権限が表示されます。

2. 利用目的

取得した情報は、投稿先チャンネルの照合、動画のアップロードと予約公開、転送の再開、重複投稿の防止、公開結果の確認、不具合対応、お問い合わせへの回答に使用します。

3. 保存と管理

認証トークンは運営者のWindows環境で、Windowsのデータ保護機能により暗号化して保存します。投稿履歴・動画ID・処理結果、台本や制作物は運営者の環境に保存し、必要な利用者にアクセスを限定します。

認証コードやトークンを公開サイトや公開ソースコードへ掲載しません。認証情報は連携の維持に必要な期間保存し、連携終了後は削除します。投稿履歴や制作物は、運用・復旧・内容確認に必要な期間保存し、不要になったものを削除します。

4. 外部サービスとの情報のやり取り

認証処理ではGoogleへ、アップロードと公開状態の確認ではYouTube APIへ、各処理に必要な情報を送信します。動画の公開設定に応じて、アップロードした動画・タイトル・説明などがYouTube上で公開されます。

台本・素材の制作や品質確認にAIサービスを使用します。入力するのは制作指示、台本、公開資料に基づく情報、確認対象の画像などです。Googleの認証トークンや、APIから取得した非公開のチャンネル情報をAIサービスに入力しません。

取得したGoogleユーザーデータを販売せず、広告配信や汎用AIモデルの学習のために使用・提供しません。法令上必要な場合を除き、上記の処理に必要な範囲を超えて第三者に提供しません。

本アプリによるGoogle APIから取得した情報の利用・他のアプリへの移転は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

5. 連携解除とデータ削除

Googleアカウントの接続管理から本アプリへのアクセス権を取り消せます。運営者は、ローカルに保存した認証情報・投稿履歴・制作物を削除できます。削除に関するお問い合わせは、下記の連絡先へお送りください。

Googleのアクセス権を取り消しても、ローカルの保存データやYouTubeへ投稿済みの動画は自動では削除されません。YouTube上の動画や予約は、YouTube Studioで管理できます。

6. 案内サイトの閲覧

この案内サイトには、運営者によるアクセス解析、広告、ログインフォームを設けていません。サイトの配信事業者は、配信・保守・不正利用防止のためにIPアドレスなどのアクセス情報を処理する場合があります。
